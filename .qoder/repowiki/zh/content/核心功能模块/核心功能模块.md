## 文章阅读功能

文章阅读功能是本应用的核心，为用户提供沉浸式的双语英语学习体验。该功能通过 `ArticleReader` 组件实现，支持中英双语切换、Markdown 内容渲染和音频同步高亮播放。

```mermaid
flowchart TD
A[用户访问文章页面] --> B{用户身份验证}
B --> |已登录| C[加载文章内容]
B --> |未登录| D[重定向到首页]
C --> E[渲染文章阅读器]
E --> F[用户选择视图模式]
F --> G[英语模式]
F --> H[中文模式]
F --> I[中英对照模式]
E --> J[用户播放音频]
J --> K[音频播放器更新时间]
K --> L[计算段落时间范围]
L --> M[高亮当前播放段落]
M --> N[滚动到高亮段落]
E --> O[用户标记文章为完成]
O --> P[调用完成API]
P --> Q[更新用户进度]
Q --> R[显示完成反馈]
```

### 中英双语切换

文章阅读器支持三种视图模式：纯英语、纯中文和中英对照。用户可以通过顶部的切换按钮自由选择。视图模式由 `viewMode` 状态管理，初始值为 `'en'`。

```mermaid

Bilingual --> Chinese : 用户点击"中文"
English --> [*]
Chinese --> [*]
Bilingual --> [*]
```

### Markdown内容渲染

文章内容使用 `bytemd` 库进行渲染，支持标准的 Markdown 语法。系统通过 `@bytemd/react` 组件集成 `bytemd`，并配置了 GFM（GitHub Flavored Markdown）插件以支持更丰富的格式。

```mermaid
flowchart TD
A[原始Markdown内容] --> B[按段落分割]
B --> C{是否为列表项}
C --> |是| D[合并到当前列表段落]
C --> |否| E{是否为空行}
E --> |是| F{当前段落非空且不在列表中}
E --> |否| G[添加到当前段落]
F --> |是| H[保存当前段落]
F --> |否| I[继续]
H --> J[重置当前段落]
G --> K[继续处理下一行]
J --> K
K --> L{是否还有更多行}
L --> |是| B
L --> |否| M[保存最后段落]
M --> N[返回段落数组]
```

### 音频同步高亮播放

音频同步高亮播放功能通过 `AudioPlayer` 组件和 `ArticleReader` 组件的协同工作实现。系统根据文章内容的单词数比例，将音频时长分配给各个段落，实现精准的同步高亮。

```mermaid
sequenceDiagram
participant 用户
participant AudioPlayer
participant ArticleReader
participant 段落计算
用户->>AudioPlayer : 播放音频
AudioPlayer->>AudioPlayer : 开始播放
loop 每秒更新
AudioPlayer->>ArticleReader : 发送当前时间(onTimeUpdate)
ArticleReader->>段落计算 : 获取段落时间范围
段落计算->>段落计算 : 计算总单词数
段落计算->>段落计算 : 按单词数比例分配时间
段落计算->>ArticleReader : 返回段落时间数据
ArticleReader->>ArticleReader : 查找当前播放段落
ArticleReader->>ArticleReader : 高亮段落并滚动
end
```

## 学习进度追踪系统

学习进度追踪系统通过 `ProgressContext` 和 `/progress` API 端点实现，记录用户的完成状态、连续签到和徽章解锁等信息。

### ProgressContext实现

`ProgressContext` 使用 React Context API 提供全局的用户进度状态。当用户登录时，系统自动获取进度数据，并在用户完成文章时刷新进度。

```mermaid
classDiagram
class ProgressContext {
+progress : UserProgress | null
+loading : boolean
+error : string | null
+refreshProgress() : Promise~void~
}
class ProgressProvider {
-status : SessionStatus
-progress : UserProgress | null
-loading : boolean
-error : string | null
-isFetchingRef : Ref~boolean~
-hasFetchedRef : Ref~boolean~
+useEffect() : void
+refreshProgress() : Promise~void~
}
class useProgress {
+() : ProgressContextType
}
ProgressProvider --> ProgressContext : "创建"
useProgress --> ProgressContext : "使用"
```

### /progress API端点

`/progress` API 端点提供两个主要功能：GET 请求获取用户进度，POST 请求更新用户进度。

```mermaid
flowchart TD
A[客户端请求] --> B{请求方法}
B --> |GET| C[验证用户身份]
B --> |POST| D[验证用户身份]
C --> E[查询用户进度]
E --> F{进度是否存在}
F --> |否| G[创建新进度记录]
F --> |是| H[返回格式化进度]
D --> I[解析请求体]
I --> J[验证文章ID和难度]
J --> K[检查文章是否已完成]
K --> |是| L[返回已完cheng]
K --> |否| M[计算新进度数据]
M --> N[检查徽章解锁]
N --> O[更新数据库]
O --> P[返回更新结果]
```

## 管理后台

管理后台为管理员提供文章管理、用户管理和统计仪表板功能，通过角色权限控制确保只有管理员可以访问。

### 功能概览

管理后台包含以下主要功能：
- **文章管理**：CRUD 操作，支持创建、编辑、查看和删除文章
- **用户管理**：查看用户列表，管理用户角色
- **统计仪表板**：显示系统关键指标，如用户总数、文章总数等

```mermaid
graph TB
A[管理后台] --> B[文章管理]
A --> C[用户管理]
A --> D[统计仪表板]
B --> E[创建文章]
B --> F[编辑文章]
B --> G[删除文章]
C --> H[查看用户]
C --> I[分配角色]
D --> J[用户统计]
D --> K[文章统计]
D --> L[增长趋势]
```
